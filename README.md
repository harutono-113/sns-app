## 概要

`Komorebi` は、毎日の小さな気づきや、作ったもの、読んだ本、学んだことを写真と言葉でそっと残しておくためのSNSです。

一般的なSNSのように大きく拡散することを目的とするのではなく、あとから見返したときに
「この頃、こんなことを感じていたな」
と思えるような、静かな記録の場所を目指して作成しました。

落ち着いた色合い、余白のあるレイアウト、読みやすい投稿カードを意識し、暮らし・創作・学びの記録が自然に積み重なっていくようなアプリを目指しています。

> ※ 現在はテキスト投稿を中心に実装しており、今後は画像投稿機能を追加して、写真と言葉で記録を残せるSNSとして拡張していく予定です。

## デザインで意識したこと

`Komorebi` という名前に合わせて、木漏れ日を感じる写真や、深緑・アイボリーを中心とした配色を使用しました。

機能を目立たせるだけではなく、投稿をあとから見返したくなるような、静かで落ち着いた雰囲気を大切にしています。

特に以下の点を意識しました。

* 深緑とアイボリーを中心に、落ち着いた印象にする
* ログイン画面でアプリの世界観が伝わるようにする
* 投稿入力欄・投稿カード・プロフィールを分け、視線が迷わない構成にする
* 投稿カードに余白を持たせ、読みやすさを優先する
* favicon も初期アイコンのままにせず、葉と光をモチーフにしたものへ変更する

## 実装で工夫したところ

### 1. 画面コンポーネントを薄くする

`Home.jsx` に投稿取得・投稿作成・投稿削除・ページネーションなどの処理をまとめすぎると、画面コンポーネントの見通しが悪くなります。

そのため、投稿まわりの状態管理や処理は `usePostsFeed` に分離し、画面側はUIの構成が分かりやすくなるようにしました。

---

### 2. Supabase との通信処理を分離する

Supabase への通信処理は `repositories` ディレクトリに集約しました。

画面コンポーネントから直接 Supabase の処理を呼び出すのではなく、
「投稿を取得する」
「投稿を作成する」
「投稿を削除する」
といった意図が分かりやすい形で呼び出せるようにしています。

これにより、画面側のコードとデータ取得処理の責務を分け、保守しやすい構成を意識しました。

---

### 3. 名前で役割が分かるように整理する

コンポーネント名やファイル名から役割が分かるように命名を見直しました。

例えば、表示用のコンポーネントは `PostCard.jsx`、データ操作用の処理は `postsRepository.js` のように分けています。

似た名前のファイルが並んで役割が分かりづらくならないように、読み手が迷わない構成を意識しました。

---

### 4. ログイン状態の復元に対応する

ページを再読み込みした際にログイン状態が失われたように見えないよう、Supabase Auth を使って現在のセッションを確認する処理を実装しました。

これにより、ユーザーが再読み込みしてもログイン状態を確認し、適切な画面を表示できるようにしています。

## ディレクトリ構成

画面の見た目、状態管理、データ取得の責務が混ざりすぎないように、以下のようにディレクトリを分けています。

```txt
src
├── components
│   ├── auth       # ログイン・登録画面で使う共通UI
│   ├── feed       # 投稿入力、投稿カード、ページネーション
│   ├── layout     # ヘッダー、ホーム画面のヒーロー
│   └── profile    # プロフィールサイドバー
├── constants      # アプリ名、写真URL、クレジット表記
├── hooks          # 投稿フィードの状態管理
├── pages          # 画面単位のコンポーネント
├── repositories   # Supabase との通信処理
└── lib            # Supabase client
```

## セットアップ

### 1. リポジトリをクローン

```bash
git clone https://github.com/ユーザー名/リポジトリ名.git
cd リポジトリ名
```

### 2. 依存関係をインストール

```bash
npm install
```

### 3. 環境変数を設定

プロジェクト直下に `.env` を作成し、Supabase の接続情報を設定します。

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_API_KEY=your_supabase_anon_key
```

### 4. 開発サーバーを起動

```bash
npm run dev
```
