# Komorebi

> 写真と言葉で、暮らしの輪郭を残すSNS

`Komorebi` は、毎日の小さな気づきや、作ったもの、読んだ本、学んだことをそっと残しておくためのSNSです。

大きく拡散するための場所というより、あとから見返したときに「この頃、こんなことを感じていたな」と思えるような、静かな記録の場所を目指して作りました。

---

## このアプリについて

| 項目 | 内容 |
| --- | --- |
| アプリ名 | `Komorebi` |
| コンセプト | 暮らし・創作・学びを写真と言葉で残すSNS |
| 想定ユーザー | 20-30代の暮らし好き・創作好き・学び続ける人 |
| 大切にしたこと | 落ち着いた雰囲気、読みやすい投稿、テンプレート感のない画面 |

---

## 作った理由

一般的なSNSは、情報の流れが速く、投稿もすぐに埋もれてしまいます。

そこで `Komorebi` では、派手さよりも「余白」や「静けさ」を大切にしました。木漏れ日のように、日々の記録が少しずつ積み重なっていくイメージです。

---

## 主な機能

| 機能 | 説明 |
| --- | --- |
| 新規登録 | メールアドレスとパスワードでアカウントを作成できます |
| ログイン | Supabase Auth を使ってログインできます |
| ログイン状態の復元 | ページを再読み込みしてもログイン状態を確認します |
| 投稿作成 | 短いテキストを投稿できます |
| 投稿一覧 | 投稿を新しい順に表示します |
| 投稿削除 | 自分の投稿だけ削除できます |
| ページネーション | 投稿一覧をページごとに切り替えられます |
| プロフィール表示 | ログイン中のユーザー情報を表示します |

---

## デザインで意識したこと

- 深緑とアイボリーを中心に、落ち着いた印象にしました。
- `Komorebi` という名前に合わせて、木漏れ日を感じる写真を使っています。
- ログイン画面では、アプリの世界観が最初に伝わるように大きな写真とコピーを配置しました。
- 投稿画面は、入力欄・投稿カード・プロフィールを分けて、視線が迷わないようにしています。
- favicon も初期アイコンのままにせず、葉と光をモチーフにしたものへ変更しました。

## ディレクトリ構成

画面の見た目、状態管理、データ取得の責務が混ざりすぎないように分けています。

```txt
src
├── components
│   ├── auth       # ログイン・登録画面で使う共通UI
│   ├── feed       # 投稿入力、投稿カード、ページネーション
│   ├── layout     # ヘッダー、ホーム画面のヒーロー
│   └── profile    # プロフィールサイドバー
├── constants      # アプリ名、写真URL、クレジット表記
├── hooks          # 投稿フィードの状態管理
├── pages          # 画面単位のコンポーネント
├── repositories   # Supabase との通信処理
└── lib            # Supabase client
```

## 実装で工夫したところ

### 画面コンポーネントを薄くする

`Home.jsx` に投稿処理やUIを詰め込みすぎないように、投稿まわりの状態管理は `usePostsFeed` に分けました。

### データ通信をまとめる

Supabase への通信は `repositories` に集約しています。画面側からは「投稿を取得する」「投稿を削除する」といった意図が読みやすくなるようにしました。

### 名前で役割が分かるようにする

`Post.jsx` と `post.js` のように似た名前が並ぶと読みづらくなるため、表示用は `PostCard.jsx`、データ操作用は `postsRepository.js` のように役割が分かる名前へ整理しました。

## セットアップ

### 1. 依存関係をインストール

```bash
npm install
```

### 2. 環境変数を設定

`.env` を作成し、Supabase の接続情報を設定します。

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_API_KEY=your_supabase_anon_key
```

### 3. 開発サーバーを起動

```bash
npm run dev
```
